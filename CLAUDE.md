# LarpCam

An original iPhone camera app: an AI composition coach that finds the shot, guides you into position, then lets you develop the photo like film.

The full spec lives in [docs/PROJECT_BRIEF.md](docs/PROJECT_BRIEF.md). Read it before doing any work, and follow its section 0 (first steps) and section 8 (milestones). Work one milestone at a time and stop after each.

Ground rules:
- Original branding only; never copy another app's name, icon, copy, or assets.
- Guidance and camera analysis default to on-device. Cloud assist is opt-in.
- Never commit API keys; use the Keychain at runtime.
- The owner's custom tweaks are listed in section 7 of the brief. Ask if they're still placeholders.
